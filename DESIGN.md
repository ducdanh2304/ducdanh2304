# Signal Atlas V2

The profile uses a dark navy editorial system with an amber signal line, teal data paths and concise technical typography. The hero establishes the identity; short section rules, a recognisable icon table, compact project diagrams and a research note change the rhythm below it.

## Build and maintenance

- Run `python build_v2.py` to regenerate the V2 SVG assets. Each SVG is self-contained and has a static state plus optional motion that respects reduced-motion preferences.
- The README references static assets through immutable GitHub raw URLs because repository-relative SVG references did not display reliably on the profile page.
- Technology icons come from [Devicon](https://github.com/devicons/devicon) through jsDelivr. Their labels remain visible if an icon is unavailable.
- The public activity chart remains generated by `render_activity.py` and refreshed by the scheduled workflow.
- Earlier artwork is retained as source history and can be removed in a later cleanup.
